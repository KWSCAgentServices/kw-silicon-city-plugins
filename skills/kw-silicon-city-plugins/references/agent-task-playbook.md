# Everyday agent task playbook

Route by the agent's intent, not by course-day labels. The 28 topics below are capabilities and practice areas, not a required 28-day course. An agent can start with one ordinary sentence. Do not make the agent choose a workflow number or provide a complex prompt.

## Understand, gather, finish

1. Identify the desired result and any property, client, geography, document, or timeframe already provided.
2. Select the applicable workflow. Gather available authorized records and current public evidence before asking for missing facts. Reuse reliable context within the current task; refresh facts that may have changed.
3. Choose routine format and length defaults. Ask only for essential missing inputs that change the result. For example, an unreadable contract requires the actual document; a missing visual headshot does not block a contract summary.
4. Produce the finished result and inspect it. Include a small set of next actions when useful, without turning a request for one asset into a whole campaign.

## Capability boundaries

Use tools exposed by the current host. If a connected service is absent, complete useful work from supplied files and accessible sources and identify only the part requiring that service. Do not claim MLS access, live CRM synchronization, delivery, scheduling, video production, or automated updates that did not occur.

Text, research, and planning can proceed independently of image generation. For actual decks, spreadsheets, documents, or videos, use the relevant available authoring capability and verify the artifact. If only content can be delivered, label it accurately rather than calling it a finished deck or video.
