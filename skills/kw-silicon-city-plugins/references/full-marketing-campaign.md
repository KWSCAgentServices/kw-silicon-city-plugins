# Full marketing campaign package

Use this campaign mode when the agent asks for a full campaign, complete marketing package, launch package, open-house campaign, or equivalent multi-asset deliverable. Do not force this package onto a request for one specific flyer, caption, or post.

## Core campaign deliverables

Unless the agent requests a different set, a full campaign includes these six coordinated deliverables:

1. **Just Listed announcement post** — a square or portrait feed graphic introducing the newly listed property. Make the exact words **JUST LISTED** a large, prominent lead message on the graphic, and begin the caption with **Just Listed**. Follow with a short, verified property-benefit subheadline, then concise key details and a buyer-focused CTA. An open-house announcement is a separate event message and does not replace the Just Listed launch post. Verify that the property is newly listed before making this claim; if it is an established listing, use an accurate listing-status announcement and explain the adjustment.
2. **Primary open-house flyer** — a print-ready and digital-friendly flyer centered on the property, event date/time, key facts, host, and listing attribution. If no open house is scheduled, create a primary listing or private-tour flyer instead; never invent event details.
3. **Property-features carousel** — four to six cards: a property-led cover followed by concise cards for the strongest verified features, spaces, or buyer benefits. Each card uses a useful authorized property photo and one main message.
4. **Property spotlight social post** — a separate feed post using a different verified value angle from the announcement, with its own short caption and three to five scannable bullets.
5. **Vertical story post** — a 9:16 story design with minimal copy, prominent property imagery, essential event or tour information, and a compact CTA.
6. **Reminder post** — an open-house reminder or event-day post when the verified event is upcoming. When there is no event, use a private-tour or details-request post instead.

Treat these as separate, publication-ready assets rather than one contact sheet. Use safe standard dimensions when the user does not specify a platform: 1080 × 1350 for portrait feed posts, 1080 × 1080 for square posts, 1080 × 1920 for stories, and 8.5 × 11 inches for the flyer. Honor user-specified sizes and channels instead.

## Shared campaign system

Collect and verify the source packet once, then reuse it across the campaign. Keep address, price, status, measurements, event details, agent contact information, listing attribution, logo, disclosures, and calls to action consistent everywhere.

Create a cohesive family through the same approved palette, typography direction, image treatment, and tone, but do not repeat one layout or headline across every piece. Give each asset a clear communication job and a distinct verified value angle. Rotate among useful property photos so the campaign reveals more of the home without using unrelated or near-duplicate images.

Every independently usable asset must satisfy the full brand, attribution, headshot, property-photo, measurement, and copy safeguards. The property remains the hero on every asset; the agent remains a smaller supporting presence. Use the original headshot where the format includes an agent block, but do not enlarge the agent simply to fill space.

Generate each visual as a complete composition through GPT Image with the same labeled source packet. Do not produce a template for later code-based assembly, and do not patch or composite campaign assets afterward with HTML, CSS, SVG, canvas, scripts, or programmatic drawing.

## Copy package

Provide finished copy with the visuals:

- one distinct verified headline for each campaign asset;
- a short caption for each feed post or carousel;
- three to five scannable bullets where the format supports them;
- a calm, buyer-focused CTA appropriate to the stage of the campaign;
- the exact host/presenter block and listing-agent attribution;
- recommended posting order keyed to the verified event date when one exists.

Do not reuse one generic paragraph for every channel. Keep captions short enough to scan and make the first line earn attention without clickbait or unsupported urgency.

## Optional add-ons

Add requested extras to the verified campaign system without replacing the six core deliverables. Examples include:

- email announcement or open-house invitation;
- postcard, door hanger, brochure, or property feature sheet;
- additional story frames or carousel cards;
- reel/video script, shot list, cover, and caption;
- paid social-ad variations;
- open-house sign, directional sign, or QR handout;
- landing-page copy or lead-follow-up messages;
- bilingual versions when the agent specifies the language and translation can be checked.

Do not silently add a paid distribution plan, publishing action, printing order, advertising spend, or external outreach. Create the requested marketing assets; perform external posting, messaging, purchasing, or distribution only when separately authorized.

## Campaign release check

Before delivery, confirm that:

- all six applicable core deliverables are present, or the agent explicitly changed the set;
- the newly listed announcement prominently displays the exact words **JUST LISTED**, its caption opens with **Just Listed**, and the verified listing history supports that message;
- every asset has a distinct purpose, headline, and useful property-photo selection;
- facts, current status, measurements, event details, attribution, logo, and contact information agree across the entire campaign;
- captions and visual copy are short, scannable, property-first, and non-salesy;
- the recommended sequence matches the verified event timeline and does not describe an event as upcoming after it has passed;
- each visual passed the same full-size property, face, logo, text, attribution, and `Approx.` review as a standalone piece.
